## New collection policy

Every source and claim retains a check date and references in the packaged JSON. `verified` describes evidential support; `reuse` describes a separate permissions review. There is no global assertion that the pilot corpus is approved for redistribution or subscriptions. No imagery is added, so no image credit is invented. Existing 2026 car assets are not attached to historical exhibits.

The new API serves a reviewed local snapshot and cannot be used as an arbitrary upstream proxy. Future ingestion should store provider ID, original request, fetched timestamp, source revision, source payload checksum, applicable terms version and licence decisions. Preserve a restricted internal raw-evidence store only where permitted; do not commit credentials or forbidden raw payloads. These live-provider acquisition jobs are not implemented in v1.

## Future Blender / glTF assets

Use a separate asset manifest containing stable entity/layout/configuration ID, creator, source URL, licence, allowed uses, modifications, SHA-256, file size, units, scale evidence, year/configuration, fidelity (`teaching`, `approximate`, `validated`) and review date. An authentic livery does not prove dimensions or aerodynamic accuracy. Require named evidence before marking a reconstruction validated. Export glTF/GLB, use level-of-detail meshes and serve only after rights review. Do not change race model selection or calibration to make a museum exhibit render.

For every served media file, the release ledger needs: path, SHA-256, creator/rightsholder, original URL and revision/check date, exact licence/version, licence evidence location, permitted uses, attribution text/location, modifications/derivative obligations, other-rights restrictions, fidelity/era and reviewer decision. If the original source is missing or ambiguous, keep it unapproved and exclude it from the affected release until resolved. Do not infer that a downloadable file or creator model licence clears trademarks, driver publicity/personality rights or all depicted content.

The Mac copy helper is deliberately binary-only and preserves branch metadata; it neither invents credits nor approves a new asset. A hash mismatch is an integration blocker, not a reason to relabel the review manifest. Private review, public fan release, subscription use and promotional redistribution require decisions for their respective scopes.
