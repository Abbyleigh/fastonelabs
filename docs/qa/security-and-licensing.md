# Security and rights review

29 October 2026. Source/code review and local negative tests, not a penetration test or approval of a deployed service. No real credentials, paid AI requests or exploit payloads were used.

## Security findings

| Priority | Finding / evidence | Required action / disposition |
|---|---|---|
| P0 public release | Both `POST /api/museum/historian` and `/api/race-engineer/ask` trust loopback client and optional Origin, not authenticated users. No account quotas, concurrency budget or global spending cap. Absent Origin passes its guard. A local reverse proxy can make a remote caller appear local. | Keep both flags `0`, deny POST at every public ingress, including path/redirect variants and direct backend addresses. Before public AI: server-verified identity, authorisation, per-user and aggregate rate/cost limits, concurrency/timeouts, CSRF if cookies, negative edge tests proving zero paid calls. Not changed in shared `main.py`. |
| P1 | Race Engineer buffers `request.body()` before its 2048-byte check; imports undeclared optional `openai` SDK once enabled. The import is outside provider exception handling. | Owner-coordinated streamed limit and declared/optional dependency handling, with enabled-path tests using fake transport; no provider calls. Keep disabled. Museum already bounds its stream, uses stdlib transport, 25s timeout, 64 KiB response bound and candidate-only AI selection. |
| P1 release | No checked-in Render service blueprint, Cloudflare Worker/Pages proxy or actual ingress configuration. Production headers, TLS, cache rules, body limits and forwarded-header trust cannot be verified. | Owner supplies sanitised configuration and running service evidence. Never infer configuration from hosting provider names. No deployment action here. |
| P1 dependency | Fresh `pip-audit -r backend/requirements.txt`: `msgpack 1.1.2`, duplicate `PYSEC-2026-3625` entries (fix 1.2.1), plus `CVE-2026-114613` (fix 1.2.3). Three entries, two identities. | Isolated dependency/constraints review against FastF1 3.9.0 and Mac Python; prefer a reviewed patched resolution, rerun full replay/asset suites and audit. No shared upgrades in QA. JSON/SQLite heritage paths do not establish a reachable MessagePack exploit. Earliest affected range caveat remains in maintainer advisory. |
| P1 reliability | Provider-backed GETs can be amplified without an ingress rate limit. `archive/drivers?search=` walks upstream pages on a cold cache. OpenF1 has retry sleeps and bounded timeouts but no shared account rate budget across requests/workers. Cache directories have no size eviction policy. | Edge rate/concurrency limits, request deadlines, cache size/expiry budgets and upstream request coalescing; coordinate separately with API owner. Current heritage GETs do not call upstream. |
| P2 confirmed QA fix | Three browser runners inherited enabled AI flags and provider keys. | Shared `reviewEnvironment` disables flags and removes keys from child env. Regression covers non-mutation of parent. Existing `.env` loading cannot override explicit disabled flags; never copy `.env` into a review. This is review safety, not public API authentication. |
| P2 | Demo serves only dist and bounded GET API routes; POST unsupported. It drops backend ETag/Cache-Control/nosniff and does not forward conditional requests, so heritage caching benefits are lost through it. Static allowlist excludes `/intro/`, causing the existing intro MP4 to 404 even with original bytes. | Documented baseline integration defects: add narrow allowlisted media types/paths and deliberate header forwarding with regression tests in a separate owner-reviewed proxy change. Not required for isolated Vite validation; do not claim demo/Cloudflare has been fixed. |
| P2 | Frontend lock audit: 0 advisories. Python requirements ranged; existing Starlette/httpx warning. | Pin/review resolved runtime and tool versions for deployment. Zero advisories is a dated database result, not proof of safety. |

No literal provider secret was identified in the reviewed frontend source/build. Provider key references are backend environment lookups. This is not an account-wide secret scan and cannot inspect Mac environment files, hosting secrets, logs or prior repository history. Vite `VITE_*` values are public by design; never put secrets there. Error responses for heritage are bounded generic 404/422 or frontend retry messages; museum provider failure falls back without echoing provider text. Race Engineer logs full exception details server-side: restrict access/retention and redact credentials. Public historian GET exposes only a configuration boolean, not key bytes; consider whether that operational detail is necessary.

No new publisher imagery/models imported. | Permission/terms review for selected facts, database extraction, publisher prose and intended public/commercial use. A citation does not grant redistribution. |
